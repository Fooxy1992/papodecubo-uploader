Papo de Cubo Uploader

Ferramenta interna do canal Papo de Cubo (youtube.com/@papodecubo).

O Papo de Cubo Uploader é um script de uso pessoal que o dono do canal Papo de Cubo roda no próprio computador para publicar no YouTube os vídeos que ele mesmo produz: envia o arquivo de vídeo, define título, descrição, tags, miniatura, playlist e data de publicação.

Não é um serviço aberto ao público. Só a conta do próprio canal autoriza o acesso, e nenhum dado de outros usuários é coletado.

Serviços de API do YouTube

Este app usa os Serviços de API do YouTube (YouTube Data API v3). Veja a Política de privacidade e os Termos de uso deste app, os Termos de Serviço do YouTube e a Política de Privacidade do Google.
