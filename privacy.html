Política de privacidade

Papo de Cubo Uploader · atualizada em 17 de novembro de 2026

O que o app acessa

O app usa os Serviços de API do YouTube apenas na conta do canal Papo de Cubo, que pertence ao próprio operador do app. Com a autorização dessa conta, ele envia vídeos, define metadados (título, descrição, tags, categoria, privacidade, agendamento), envia miniaturas, adiciona vídeos a playlists e lê as informações básicas do canal para confirmar em qual canal está publicando.

O que é armazenado

Os tokens de acesso OAuth ficam salvos apenas no computador do operador, num arquivo protegido. Nenhum dado é enviado para servidores de terceiros, vendido, compartilhado ou usado para publicidade. O app não coleta dados de outros usuários do YouTube.

Serviços de API do YouTube

Este app usa os Serviços de API do YouTube. Ao usá-lo, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em security.google.com/settings/security/permissions. Ao revogar, os tokens salvos deixam de funcionar e são apagados do computador do operador.

Retenção

Os tokens são mantidos enquanto o app for usado e apagados quando o acesso é revogado ou o app deixa de ser usado. Nenhum outro dado do usuário é guardado.
